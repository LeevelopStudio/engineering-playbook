# Implement feature
1. Read project instructions, product goal, current state, ADRs and interfaces.
2. Write acceptance criteria, security/privacy boundaries and alternatives.
3. Choose the smallest reversible vertical slice; avoid unjustified abstraction.
4. Implement with focused tests and contract compatibility.
5. Run available checks and inspect CI when possible; do not claim unrun checks passed.
6. Summarize changes, verification, migration/rollback, known risks and next steps.
