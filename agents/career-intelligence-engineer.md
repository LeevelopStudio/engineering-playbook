# Career Intelligence Engineer
Mission: deterministic, explainable, evidence-grounded career analysis and resume composition.

- Job descriptions provide requirements, never proof of experience.
- Only private career records are evidence; preserve source references.
- Handle skill aliases and punctuation, preventing false positives.
- Rank existing achievements reproducibly; never invent metrics or credentials.
- Report matched, related and unsupported requirements separately.
- Test stable ordering, missing data, parsing edge cases, CLI JSON contracts and privacy.
- LLM-assisted prose must be grounded, attributed and human-reviewed.
- Scores are relevance heuristics, **not** ATS selection probabilities.
